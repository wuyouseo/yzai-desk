使用帮助

从第一次打开，到把桌面整理成顺手的样子。这里汇集了咏智桌面常用功能的操作方式。

使用指南开始使用今日总览日程提醒四象限备忘录剪贴板番茄时间AI 助手桌面挂件设置与备份

开始使用

  1. 在 GitHub Releases 获取 Windows x64 安装包，并按安装程序提示完成安装。
  2. 打开咏智桌面，在左侧选择需要的功能；也可以通过系统托盘访问常用入口。
  3. 进入“系统设置”，按需调整外观、桌面挂件、数据位置和 AI 服务。

支持 Windows 10 / 11 x64。当前尚未配置 Windows 代码签名和自动更新，请以发布页面的版本说明为准。

今日总览

打开“今日总览”，可查看今日安排、待完成日程、专注数据与剪贴板记录。点击“添加日程、提醒或备忘”即可创建事项，也可从总览进入日历或专注页面。

日程提醒

  1. 进入“日程提醒”，使用日历浏览月份或返回今日。
  2. 点击“新建事项”，选择日程、提醒或备忘，填写名称和时间后保存。
  3. 日程可开启到点提醒；提醒会在设定时间弹窗。日历中的“备忘”仅用于记录，不会自动弹窗。

四象限

进入“四象限”创建任务，按照重要和紧急程度选择对应区域。可以在不同象限间调整任务，并通过筛选查看事项，帮助自己先处理最重要的工作。

备忘录

  1. 进入“备忘录”，点击新建按钮，输入标题和内容；编辑内容会保存到本机。
  2. 使用搜索查找记录，在更多操作中可置顶、导入或导出文本。
  3. 如需锁定内容，先在系统设置中设置统一备忘录密码，再点击编辑器工具栏的锁图标。

剪贴板

进入“剪贴板”查看和搜索历史记录，选择需要的内容快速复制。常用记录可置顶；“一键清理”会清理未置顶记录。敏感内容相关选项可在系统设置中调整。

番茄时间

  1. 进入“番茄时间”，选择工作时长或填写自定义时长，然后点击“开始专注”。
  2. 专注过程中可暂停、继续或重置；计时开始后，需先重置才能更改时长。
  3. 也可以使用专注挂件操作计时，并在页面中查看专注统计。

AI 助手

  1. 打开“系统设置 → AI 服务”，选择预设服务或添加自定义服务。
  2. 填写协议类型、Base URL、模型 ID 和 API Key，点击“保存并启用”。自定义服务需兼容所选协议，并允许桌面 WebView 发起跨域请求。
  3. 进入“AI 助手”开始对话；可查看会话记录并导出回答。服务是否收费及具体限制以所选服务商为准。

AI 请求在主动配置服务后发送至对应服务商。新建的本地备份不包含 AI 密钥，跨电脑恢复后需要重新填写。

桌面挂件

在“系统设置 → 桌面挂件”中选择日历、专注、天气或备忘录挂件并开启。天气城市可在设置中填写并按回车保存。

可拖动标题栏移动挂件，拖动边缘或四角调整大小；在挂件菜单或设置中心可锁定位置、保存和恢复布局。

设置、备份与恢复

在系统设置中可调整主题、开机启动、天气城市及数据目录。进入“数据与备份”点击“立即备份”创建本地备份；导入备份会替换当前数据，操作前应用会自动保留当前数据。

新建备份不包含 AI 密钥。旧版数据或旧备份可能仍含明文密钥，请妥善保管。使用过程中遇到问题，可前往 GitHub Issues 反馈。
