# 咏智桌面工具（YZai Desk）开发记录与实施计划（v0.5.0）

最后更新：2026-07-18

本文档同时记录当前开发进度、已经验证的能力、未完成事项和后续实施顺序。详细产品需求与架构边界见 [requirements_and_architecture.md](./requirements_and_architecture.md)。

## 1. 当前结论

项目已经进入 **v0.5.0 可运行测试版** 阶段，不再是后台骨架或静态 UI 原型。

- 八个 Tauri 窗口均已实现：配置中心、组合挂件、日历/便签/番茄钟/天气四个独立挂件、快捷助手和提醒通知。
- React 前端、本地数据、剪贴板监听、日程调度、番茄钟、加密便签、全局快捷键和 Windows 自启动已经接通。
- 项目专用 Rust GNU + LLVM-MinGW 工具链已经恢复，开发版可以在真实 Windows 桌面运行。
- 已完成一轮真实窗口功能测试，并根据测试结果修复多项编译、窗口和数据一致性问题。
- 当前版本适合继续内部测试，不应标记为正式发布版；v0.5.0 Windows x64 NSIS 安装器已经生成并完成文件级校验。

### 3.2 测试中发现并已修复

1. Windows GNU 动态库导出数量超限，程序无法链接。
2. release 程序依赖 `libunwind.dll`，不能脱离工具链目录启动。
3. 快捷助手使用内部窗口调用，`Esc` 无法可靠隐藏。
4. 番茄钟仅保存在内存，重启后丢失。
5. 挂件首次读取番茄状态存在启动竞态。
6. 挂件速记可能复用第一条加密便签并写入明文字段。
7. 前端保存完整旧数据快照，可能覆盖后台刚更新的番茄状态。
8. 配置中心缺少容易发现的挂件显示入口。
9. AI 服务双栏布局在中等宽度窗口中被裁切，且新增空服务会被立即持久化。
10. 便签正文逐字符持久化容易造成输入卡顿及异步保存覆盖，已改为本地草稿并在失焦时保存。
11. 首版 v0.5.0 NSIS 安装器遗漏 GNU 构建所需的 `WebView2Loader.dll`，导致安装后无法启动；现已将 x64 DLL 作为应用资源安装到 EXE 同目录，并完成安装包解包和启动存活验证。
