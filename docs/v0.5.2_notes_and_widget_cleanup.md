# v0.5.2 便签修复与旧组合挂件清理

检查日期：2026-07-21

## 便签空白页修复

配置中心的便签页需要遍历、搜索和排序全部便签；独立桌面便签只读取固定的桌面速记记录。因此，旧版数据中只要有一条记录字段缺失或类型异常，就可能只影响配置中心页面。

本次处理：

- 过滤 `null`、字符串和数组等无效便签记录。
- 将便签 ID、标题、正文和分类统一为安全类型。
- 无效更新时间统一为可排序的兼容时间。
- 补齐 `encrypted`、`pinned` 和加密字段默认值。
- 当前选中的便签被删除或过滤后，自动选择第一条有效便签。
- 搜索和排序不再直接调用不确定类型的数据字段。

## 旧组合挂件清理

已经删除：

- `widget` Tauri 窗口配置。
- `#/widget` 前端路由和 `WidgetView.jsx`。
- 系统托盘中的“显示/隐藏桌面挂件”和“锁定/解锁挂件布局”。
- 组合挂件显示、锁定、位置恢复和 IPC 命令。
- 设置页中的“显示组合挂件”按钮和相关状态查询。
- 组合挂件专用 CSS。
- 新数据中的 `widget_locked`、`widget_position`、`widget_size` 默认字段。

升级启动时只删除以上三个废弃布局字段。四个独立挂件的显示状态、位置、尺寸及所有用户内容保持不变。

## 验证结果

- 异常旧数据测试：包含空记录、错误字段类型和无效日期时，便签列表、标题输入框和正文编辑框均可显示。
- 设置页显示 4 个独立挂件，不再包含“组合挂件”。
- 浏览器控制台无错误。
- `npm.cmd run build` 通过。
- `npm.cmd run desktop:check` 通过。
- `npm.cmd run desktop:build` 通过。
- 最终 Tauri 静态窗口仅为 `settings`、`quick-panel`、`notification`；四个独立挂件仍按需创建。
