## 下一批优先任务

1. 恢复 Rust stable 与 `x86_64-pc-windows-gnu` 工具链，运行 `cargo fmt`、`cargo check` 和 `npm.cmd run tauri dev`，修复所有编译或权限问题。
2. 在真实 Tauri 多窗口中完整联调：托盘菜单、`Alt + Space`、失焦隐藏、通知定位、桌面置底和鼠标穿透。
3. 持久化挂件窗口位置、尺寸与锁定状态，重启后自动恢复。
4. 重构番茄钟为可暂停/恢复且可跨重启恢复的持久状态，统计同时保存次数和分钟数。
5. 完成便签分类/标签与更友好的密码弹窗；增加加密便签的错误次数节流和密码确认。
6. 为 AI 对话增加 Markdown/代码块渲染、会话历史、取消生成和网络超时处理。
7. 增加 Rust 单元测试、前端关键流程测试、备份恢复测试和性能基准，再进入安装包发布。

## 发布边界

当前版本可以作为本地 UI/功能原型继续联调，但不应标记为正式发布版。尤其需要在 Rust 工具链恢复后重新验证数据保存、剪贴板后台任务和 Windows 窗口控制。
