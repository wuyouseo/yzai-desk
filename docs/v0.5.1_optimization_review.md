# 咏智桌面工具 v0.5.1 优化与兼容性检查

检查日期：2026-07-21

## 本次已处理

1. 卸载清理
   - NSIS 卸载前删除 `HKCU\Software\Classes\DesktopBackground\Shell\YZaiDesk`。
   - 同时删除应用自建的 `YZaiDesk` 开机启动项。
   - 右键入口从 `Position=Top` 调整为 `Position=Bottom`。
   - 应用升级时会先重建菜单分支，避免残留旧子菜单。

2. Windows 11 挂件兼容性
   - 四个独立挂件改为按需创建，不再随应用一次启动四个隐藏 WebView2 页面。
   - 自绘高频拖动改为 Windows 原生拖窗。
   - 拖动和缩放位置改为停止操作后合并写盘。
   - 不再把 WebView2 窗口重新挂接到 Progman，规避新系统和部分显卡驱动下的合成器卡死风险。
   - 新增默认开启的“挂件兼容模式”，关闭高开销背景模糊和动画。
   - 数据文件读写增加进程内串行事务，避免剪贴板、提醒、便签和挂件同时写入时互相覆盖或争抢临时文件。
   - 普通重复启动会复用已有进程；开机启动改为后台模式，不再弹出配置中心。

3. 便签体验
   - 自动保存失败时不再永久显示“保存中”，会明确显示“保存失败，请重试”。
   - 右键快捷指令监听增加长度和超时限制，异常本地连接不会一直占住监听线程。

## 已完成验证

- `npm.cmd run build`：通过。
- `npm.cmd run desktop:check`：通过。
- `npm.cmd run desktop:build`：通过，生成 v0.5.1 x64 NSIS 安装器。
- 生成的 NSIS 脚本已确认包含并调用 `NSIS_HOOK_PREUNINSTALL`。
- Edge/Playwright 浏览器检查：配置中心与 300×250 独立便签均正常渲染，无错误遮罩、无控制台错误、无页面溢出。
- 当前电脑的旧版右键注册表残留已清除。

尚未完成：没有在 Windows 11 25H2 实体机上执行安装、升级、睡眠唤醒、多显示器和卸载全流程，因此不能把代码级兼容修复等同于 25H2 实机回归通过。

## 后续优化建议

### P0：正式发布前

- 建立实体机回归矩阵：Windows 10 22H2、Windows 11 23H2/24H2/25H2；Intel/AMD/NVIDIA；100%/125%/150%/200% DPI；单屏和多屏；睡眠唤醒与 Explorer 重启。
- 为安装器和主程序做代码签名，并加入可靠的升级/回滚策略。
- 将 AI API Key 从 `data.json` 和普通 JSON 备份迁移到 Windows Credential Manager 或 DPAPI，备份默认不携带密钥。
- 增加崩溃日志和“复制诊断信息”入口，至少记录系统版本、WebView2 版本、显卡、窗口类型和最近错误，不记录用户正文。

### P1：近期体验

- 天气城市输入目前只改变显示名称，经纬度仍保持原值；应加入城市搜索与地理编码，避免显示“上海”却读取北京天气。
- 挂件恢复位置应根据当前显示器工作区重新校准，防止拔掉副屏或 DPI 改变后窗口跑到屏幕外。
- 增加数据文件损坏恢复流程：保留最近可用备份、启动时校验并提供恢复提示。
- 收紧 Tauri CSP 和窗口能力权限；当前 `csp` 为空且全部窗口共享较宽权限。
- 增加自动化测试：便签快速连续输入、剪贴板与提醒并发写入、重复启动、覆盖升级、卸载注册表清理。

### P2：产品完善

- 增加自动更新和版本发布说明页。
- 让用户在卸载时明确选择“保留本地数据”或“同时删除本地数据”；默认建议保留。
- 为天气和 AI 网络请求增加统一超时、取消和重试提示。
